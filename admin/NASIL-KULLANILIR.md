# Personel için — panel kullanımı

Adres: **https://ozmaksan.netlify.app/admin/**

## Giriş
1. **Giriş yap** butonuna basın
2. Davet e-postanız + şifreniz

Şifre yoksa yöneticiden yeni davet isteyin.

## Ürün eklemek / değiştirmek
1. Solda **1 · Ürünler**
2. Mevcut ürüne tıklayın **veya** sağ üst **Yeni Ürün**
3. Ad, kategori, kısa açıklama, fotoğraf, açıklama yazın
4. Sağ üst **Kaydet** → **Publish** / **Yayınla**
5. 1–2 dakika sonra sitede görünür: https://ozmaksan.netlify.app/urunler.html

## Haber eklemek
1. Solda **2 · Haberler**
2. **Yeni Haber**
3. Başlık, tarih, özet, metin, fotoğraf
4. **Kaydet** → **Publish**

## Firma bilgisi (telefon / adres)
Solda **3 · Firma bilgileri** — seyrek kullanılır.

## Dikkat
- Kaydettikten sonra mutlaka **Publish** basın (yoksa site güncellenmez)
- Çok peş peşe giriş denemeyin (kilitleyebilir)
- Ev Wi‑Fi açmazsa **mobil veri** deneyin
